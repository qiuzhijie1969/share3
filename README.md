# share3

这是一个用 GitHub Pages 分享 HTML 课件和演示文件的仓库。

## 分享链接

- 首页索引：<https://qiuzhijie1969.github.io/share3/>
- 现有页面：<https://qiuzhijie1969.github.io/share3/children-poetry-review.html>

## 使用方式

1. 单个 HTML 文件可以直接上传到仓库根目录。
2. Keynote 导出的 HTML 演示建议放进 `slides/` 目录，每个演示一个独立文件夹。
3. 每个演示文件夹里保留 Keynote 导出的完整内容，尤其是 `index.html` 和资源文件。
4. GitHub Pages 发布完成后，首页会自动列出仓库里的 HTML 页面。

## 推荐目录

```text
share3/
  index.html
  .nojekyll
  children-poetry-review.html
  slides/
    lesson-01/
      index.html
      ...
    lesson-02/
      index.html
      ...
```

## 链接规则

- 根目录文件：`https://qiuzhijie1969.github.io/share3/文件名.html`
- `slides/` 演示：`https://qiuzhijie1969.github.io/share3/slides/文件夹名/`
